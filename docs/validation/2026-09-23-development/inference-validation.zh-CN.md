# 合成回归推断验证：CPU float64 初筛

本次完成 **MCAR、MAR 各 200 个独立模拟数据集**，每份 `n=300`、`m=5`，共 400 次多重插补、2,000 次 bootstrap EM 拟合。所有拟合收敛，零失败、零警告、零自适应先验启用、零伪逆调用。这里检查特定合成设定下的统计推断，不是 GPU 性能实验，也不是所有数据或原版 Amelia 统计等价性的证明。

完整逐次记录见 [`inference-validation.json`](inference-validation.json)，包括每次生成/掩码/插补种子、参数估计、方差、置信区间、迭代数、失败状态、版本及源文件哈希。报告不包含私人文件路径或设备标识。

## 设定

- `(x1, x2)` 服从二维正态，均值为 0，方差均为 1，相关系数 0.3。
- `y = 1 + x1 + 0.5*x2 + noise`，其中 `noise ~ N(0,1)`，且独立于协变量。
- 目标量是回归 `y ~ 1 + x1 + x2` 中的 `x1` 系数，真值为 **1**。
- 两场景的 `y` 始终观测；每个协变量的期望缺失率为 **20%**。这是协变量缺失率，整个三列表的期望缺失率约 **13.33%**。
- MCAR：`x1/x2` 的单元独立随机缺失。
- MAR：`x1/x2` 的缺失概率只依赖始终观测的 `y`；使用斜率为 1 的 logistic 函数，截距按该次已观测 `y` 校准，使协变量的平均期望缺失率为 20%。
- 使用本项目 native `amelia()`，CPU float64，普通 bootstrap，`tolerance=1e-4`、`autopri=0.05`、无显式 `empri`，EM 上限为 500。实际每次拟合需要 4–13 轮。
- 主种子 `20260923`；场景、重复序号分别派生独立的生成/掩码/插补种子，改变模拟预算不会改变前面已定义的模拟。PyTorch 和 BLAS 均按单线程设置。

实际平均协变量缺失率分别为 19.914% 和 20.017%。原始系数估计的跨模拟标准差分别为 0.06617、0.06803；平均 pooled 标准误分别为 0.06685、0.06856。

这些结果没有显示该设定下明显的偏差或区间失效，仍有相当的 Monte Carlo 不确定性。两个覆盖率区间都包含名义 95%，但**不能把“没有发现差异”当成统计等价**；本次没有预设等价界限，也没有执行原版 R 的并列推断模拟。需要更精确覆盖率结论时，应预先增加模拟次数，而非根据有利结果选择种子。

## Pooling 与不确定性口径

每份完成数据先分别做普通最小二乘。每份 `x1` 方差采用同方差 OLS 公式，残差方差为 `SSE/(n−3)`，通过 QR 分解计算系数方差。

令 `Q_j`、`U_j` 分别为第 j 份系数估计及其采样方差。使用标准 Rubin 标量公式：

```text
Qbar = mean(Q_j)
Ubar = mean(U_j)
B = sum((Q_j − Qbar)^2) / (m − 1)
T = Ubar + (1 + 1/m) B
ν = (m − 1) [1 + Ubar / ((1 + 1/m) B)]²
95% CI = Qbar ± t_(ν,0.975) sqrt(T)
```

当 `B=0` 时取 `ν=∞` 的正态极限。本轮**没有采用 Barnard–Rubin 的有限完整样本自由度修正**，因此不要将它与默认采用该修正的 pooling 软件输出逐项等同。公式来源及差异可核对 [mice 标量 pooling 文档](https://amices.org/mice/reference/pool.scalar.html)和 [Vink 与 van Buuren 的 pooling 论文](https://stefvanbuuren.name/publications/2014_MI_sample_population.pdf)。

偏差 MCSE 为独立模拟系数估计的样本标准差除以成功次数的平方根；覆盖率 MCSE 为 `sqrt(p*(1−p)/N_success)`，另报告精确二项区间。主覆盖率以成功且全部拟合收敛的数据集为分母，失败和不收敛次数另列，同时提供失败一律按未覆盖计的结果。本次无失败，两种分母得到相同覆盖率。

## 可复现性与验证

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv/bin/python scripts/validate_inference.py \
  --replicates 200 --n 300 --m 5 --threads 1 \
  --time-budget-seconds 300 \
  --output results/local/inference_validation-repeat.json
```

脚本拒绝覆盖已有结果。Windows 使用 `.venv\Scripts\python.exe` 并设置对应环境变量。主机不同或数值库版本变化时，不承诺逐位相同；报告保存精确版本、代码哈希和每次随机种子。

本次运行环境为 Python 3.12.13、NumPy 2.5.3、SciPy 1.18.1、PyTorch 2.14.0、macOS arm64。400 次模拟的循环耗时约 3.62 秒，此数值仅用于记录本次验证成本，不能解释为相对其他实现的加速比。

11 项离线测试覆盖手算 Rubin 示例、零 between variance 的正态极限、无效输入拒绝、解析 OLS 示例、掩码可复现与响应始终观测，以及失败不能从质量结果中消失。运行后独立从 400 条逐次记录重新计算了偏差、MCSE、覆盖次数并核验源文件哈希。

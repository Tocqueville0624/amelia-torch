# Amelia Torch 阶段总结：已有数据能支持什么

**本地 RTX 3080 的 90 列、10 万行任务，原生 CUDA64 从原版 R 串行的 230.560 秒缩短到 22.115 秒，整体快 10.43 倍；其中相对原生 PyTorch CPU64 的 GPU 收益为 1.49 倍。** 完整 R 混合 CUDA64 为 101.640 秒，相对混合 CPU64 快 1.09 倍。低维任务多数无 GPU 收益；这些有限性能与数值检查不等于完整统计验收通过。

最初整理于2026-09-27 UTC（本地9月26日晚），当时用户暂停Colab。随后用户授权本地RTX 3080测试并要求发布报告，本页据已有记录补充Windows结果，没有新增拟合。项目仍是**公开开发快照，尚未达到完整首版验收**。

本地Windows现已完成native/reference 18/18及R hybrid 12/12配置，共210调用/1,050插补。90列任务native CUDA64/32比同精度CPU快1.49/1.31倍，比原版R串行快10.43/11.44倍；完整R hybrid的同精度GPU收益仅1.09/1.05倍，比R snow4快1.20/1.21倍。低维任务多数无GPU收益。跨实现的10倍包含实现与工作流差异；3080/T4两台主机的90列CUDA64耗时比约1.90，不能解释为显卡本身的受控性能比。三组输入均100k行，也不能从不同列数的数据集证明普适规模规律。完整条件、局限和原始记录见[Windows报告](2026-09-27-windows-rtx3080/README.md)。下文T4与Mac记录保持各自历史范围。

## 主要结论

1. **项目已取得可复核的加速结果。** 三组各 10 万行的数据上，原生 Python 路线使用 T4 CUDA64，相对同一云主机、同精度的 PyTorch CPU64 快 **1.21–1.91 倍**。完整重复、源码和数据哈希已保存。
2. **T4已存R兼容路径的收益较小，未超过该机原版并行基线。** 已回收的五组同精度 CPU/GPU 配对快 **1.281–1.407 倍**，但五个 GPU 配置均慢于同机原版 R snow2。该套件因 VM 丢失只保留 11/12 配置，不能称完整通过。
3. **Apple GPU 在这些任务上没有加速。** M4 上，native MPS32 比同机 CPU32 慢约 **51%–70%**；R hybrid MPS32 慢约 **13%–33%**。
4. **可运行、数值检查通过和统计验收通过是不同结论。** Mac 正式推断实验全部拟合成功，但预设 MCAR 门槛未全通过；CUDA 的同类正式实验未执行完成。因此现在不能声称全部统计质量验收通过。

这已经是一项有结果、有负面发现、能复现的工程研究项目；当前最准确的定位是 Amelia 兼容移植与跨设备评估，而非承诺所有研究者都能获得 GPU 加速的成熟替代包。

## Linux T4：原生 Python 路线完整结果

| 数据 | 原版 R 串行 | 原版 R snow2 | native CPU64 | native CUDA64 | CPU64 / CUDA64 |
|---|---:|---:|---:|---:|---:|
| Covertype | 23.016 | 20.827 | 9.870 | 6.172 | **1.599×** |
| Household power | 16.239 | 14.649 | 5.592 | 4.616 | **1.212×** |
| YearPredictionMSD | 206.580 | 175.359 | 80.326 | 42.049 | **1.910×** |

同精度 float32 的 CPU/GPU 比值分别为 **1.645×、1.760×、1.754×**。本机 CPU 配额为两核；原版 snow2 使用两个 worker、每个 worker 的 BLAS 为单线程。不能将它解释成 GPU 相对任意高核数服务器的优势。

完整套件包括 **18 个配置、126 次调用、630 份插补**；记录内的收敛、观察值不变、全部 heldout 有限且无漏计等检查通过。CUDA 活跃张量分配峰值约 304.4 MiB，**不是总显存或峰值宿主内存**。计时包括规定的传输与输出步骤，全部重复和失败字段均保留。

native CPU 本身也比这里的原版 R 快；相对 R 的差值包含移植实现、数值库及工作流差异，不能全算成 GPU 的功劳。native 目前只支持连续数值 EMB，不等同于已加速整个 Amelia 高级功能集。[完整报告与原始归档](2026-09-26-colab-native/README.md)。

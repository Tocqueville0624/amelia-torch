# 证据摘要

[English](2026-09-27-evidence-summary.md) · [文档目录](../README.zh-CN.md)

项目仍为**开发快照**。GPU 性能取决于任务和接口；Windows RTX 3080 已完成指定连续数据任务的基准，但完整统计验收尚未完成。Colab 实验暂停。本页汇总已公开记录，不新增拟合或模拟。

## 性能

三组数据各含 100,000 行，分别为 10、7、90 个数值变量。每配置的单次调用生成五份插补，两次预热后正式重复五次。耗时单位为秒，取中位数。速度比只比较同机、同实现、同精度，大于一表示 GPU 更快。

| Covertype | 15.280 | 8.340 | 5.484 | 4.955 | 1.107× | 16.670 | 17.790 |

Year 的原生 CUDA64/32 相对原生 CPU 快 1.49/1.31 倍，混合路线相对混合 CPU 快 1.09/1.05 倍。原生相对 R 串行的 10.43/11.44 倍差异包含实现、数值库和流程差异；原生支持的选项少于混合路线。低维任务多数收益有限或更慢。[Windows 报告](2026-09-27-windows-rtx3080/README.zh-CN.md)保留全部 30 配置、210 次调用和 1,050 份插补。

## 比较范围

完整来源行抽样后加入块状 MCAR，缺失率为 30%/28.57%/30%，模式数为 8/7/8。这不是全量来源数据，也不是逐格独立 MCAR 或 MAR。行数相同而内容不同的三个数据集不足以证明一般规模规律。完整压缩原包约 232 MiB，归属、哈希、许可样本和下载脚本见[数据说明](../datasets.zh-CN.md)。

五次重复的 IQR 表示离散程度，不是性能差异的置信区间。计时包括各报告定义的传输和输出，R 混合路线还包括桥接与保留的 R 流程。没有 profiling 隔离通信成本。跨主机 RTX 3080/T4 或 Mac/CUDA 比值混有 CPU、线程预算、操作系统、软件及源码差异。Torch 张量分配峰值不等于总显存或宿主 RAM。

## 数值与统计验证

| 证据 | 已记录结果 | 剩余范围 |
|---|---|---|
| ef729c0 的 Windows/macOS/Linux CPU CI | 每平台 307 项 Python、九个 R 文件和下游示例通过 | CPU CI 不验证 GPU 或任意系统组合 |
| 固定 CUDA 案例 | T4 完成最初十五步验证；RTX 3080 的原生和 R 混合两精度案例通过 | 后增 CUDA 边界及正式 G5 未完成 |
| 已安装 Mac RStudio 工作流 | reference/hybrid CPU64、RDS/CSV、Data Viewer 和诊断图通过 | 原版 AmeliaView 未验收 |
| Mac G5 五路线 | 2,100 次调用、10,500 次拟合完成，MAR 和有限压力标准通过 | 预设 MCAR 标准未全部通过 |
| 替代 Colab VM | 第二轮 306 项 Python 通过、一项失败 | 停在九个 R 文件、后增 CUDA 边界及 G5 之前 |

Windows 混合与原版配对摘要的最大相对差约为：归一化 heldout RMSE 0.059%、协方差 0.95%、Rubin 组间方差 3.05%，迭代次数最多相差七次。没有预设数值等价门槛，也没有完整矩阵逐格对照。原生与 R 使用不同随机流。

已保存的 Mac CPU32/MPS32 输出中，Covertype 补值最大差异达 **0.173 个 truth 列标准差**。对照仅限首个正式调用的前 1,000 行，不建立一般误差界限，也不证明根因。详见[已保存输出对照](2026-09-26-native-parameter-comparison/README.zh-CN.md)。

Mac G5 中，原版 R 和混合 MCAR 覆盖率为 195/200（97.5%）；预设 90% 蒙特卡洛区间上界 99.009876% 超出 99% 限制。原生为 192/200（96%），与 R 的配对差区间下界 −5.028703 个百分点，超出 −5 的限制。CPU 和 MPS 分类一致。这些结果未全部通过，也不足以证明 GPU 独有缺陷。门槛保持不变，见 [G5 报告](2026-09-26-g5-mps/README.zh-CN.md)和[冻结协议](g5-prespecified/README.zh-CN.md)。

## 发布状态

已有证据涵盖三个 Python/R 接口、固定原版语义、跨平台 CPU 安装、实际 RStudio 工作流、公开数据基准、同机 GPU 加速与负收益，以及保留的统计失败结果。项目尚不是完全验收的 Amelia 替代包，未发布 PyPI 或 CRAN。

[替代 Colab 记录](2026-09-27-colab-recovery/README.zh-CN.md)保留 R/扩展冲突、Ruff 版本差异和临时环境缺少 NumPy 的问题。七个 checkpoint、54 个文本文件记录恢复尝试，不代表验收完成。继续云端工作前仍需验证安装器保护和依赖继承。额外 1,000 次 MCAR 仍是[独立且未执行的提案](g5-mcar-followup-proposed.zh-CN.md)。未来测量须单独保留来源，不能用于补齐旧会话的缺失结果。

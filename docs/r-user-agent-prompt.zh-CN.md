# R 工作流提示词

[English](r-user-agent-prompt.md) · [文档目录](README.zh-CN.md)

此模板用于向编程助手说明 R 插补任务，在执行前明确数据和模型选择。请结合[兼容表](amelia-compatibility.zh-CN.md)，并保留全部插补结果用于下游合并推断。

```text
我使用 R。请使用 https://github.com/Tocqueville0624/amelia-torch 帮助插补数据，并返回可在 R 中使用的结果。

安装软件或处理数据前，先确认：
- 数据集路径、格式、表或工作表；待插补变量、预测变量、ID/排除列、变量类型和缺失值编码。
- 下游分析及类别、变换、边界、先验、面板/时间序列要求；如有现有 Amelia 代码，请先核对。
- 插补份数 m、seed、bootstrap 方法、收敛容差、迭代上限及正则化。解释不熟悉的选项，提出默认值供确认。
- 操作系统、R/Python 环境、GPU、内存/时间预算，以及是否允许安装或上传数据。
- 输出目录、R 可读格式及所需诊断。

必要信息清楚后，阅读仓库的兼容表和算法契约，确认执行方案。仅在原生 Python 支持全部所需功能时使用该路线，否则说明 reference/hybrid 选项。不得为加速而丢弃参数或改变统计假设。默认 CPU float64；GPU、低精度或试跑基准须先确认。

方案确认后生成可复现脚本，执行插补，保存每份完成数据及行 ID、变量元数据。保留观察值和已记录的全空行行为，报告收敛、警告、失败和完整调用耗时。保留全部插补用于下游合并，提供 R 读取和分析代码，说明剩余验证限制。未经允许，数据保持本地。
```
